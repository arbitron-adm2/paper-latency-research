# Source provenance

This private code export combines the project's research/runner code, strategy source supplied for the joint research, and snapshots of the existing PaperTrade and Binance Python clients. Strategy family names and upstream public contract addresses are retained where needed for compatibility. Personal account addresses and historical account data are not distributed.

No new license or ownership claim is imposed on contributed source. Review the respective authors' rights before making this repository public or redistributing contributed modules.
